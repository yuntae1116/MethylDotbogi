# MethylDotbogi

**A Python/R-based toolkit for whole-genome bisulfite sequencing (WGBS) analysis and visualization.**

MethylDotbogi is a research-oriented bioinformatics tool designed to streamline DNA methylation profiling and the visualization of WGBS results. It brings together analytical and plotting workflows for examining methylation patterns across genomic regions.

## Features

- **DNA methylation profiling:** Summarize methylation patterns from WGBS-derived data.
- **Genomic window analysis:** Explore regional patterns of DNA methylation.
- **Gene and transposable-element metaplots:** Visualize aggregated methylation patterns around genes and transposable elements (TEs).
- **Chromosome-wide visualization:** Examine the distribution of methylation signals along chromosomes.
- **Python/R workflow:** Combine data processing and statistical visualization in a research-oriented workflow.
